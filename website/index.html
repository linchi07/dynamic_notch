01 NATIVE IDLE NOTCH

静默于顶，
未唤时本是纯粹之境。

无播放、无弹窗时，Dynamic Notch 彻底回归隐退。 展示为原生极简的物理黑曜石刘海轮廓，零多余图标与常驻翅膀， 宛若硬件本身，守护视线最纯净的心流宁静。

  • 185×34 纯净物理规格，紧密贴合 MacBook 屏幕原厂轮廓
  • 空闲时零视觉掠夺，不占菜单栏任何宝贵空间
  • 休眠待机期系统负载归零，保持冰凉长续航
↓ 向下滚动，见证音乐响起时长出灵动双翼与跳动频谱
02 COMPACT WINGS LIVE ACTIVITY

旋律升起，
双翼伴随波形律动。

当网易云音乐、Spotify 或 Apple Music 响起，刘海向左右灵动舒展出紧凑双翼： 左翼微缩专辑封面静候，右翼跳动着 iOS 同款 6 柱物理谐波频谱（Harmonic Physics Oscillation）， 以充盈阻尼感的流体波形随节拍起伏。

  • 左右双翼自然延伸，左翼 20×20 封面，右翼声学频谱
  • iOS-Aligned 6 柱声学波形，模拟真实流体阻尼谐波跳动
  • 毫秒级 MediaRemote 监听，暂停时平滑回归静止
03 EXPANDED MEDIA ISLAND

轻触展开，
声色流动的媒体中枢。

鼠标悬停或轻点刘海，瞬时展开为 460×180 沉浸媒体岛。 86×86 专辑封面投射动态弥散光晕，实时流动歌词， 精密的无级时间进度条与触控工具栏，带来沉浸式音乐盛宴。

  • 流光漫射背景算法，依据专辑封面色调动态映射
  • 实时歌词流与多播放器来源一键无缝切换
  • 顶部状态栏精确显示电池百分比与快速镜面自拍
04 SNEAK PEEK TRACK ALERT

曲目更迭，
水滴般自然垂落。

每当后台切歌，刘海下方瞬间轻盈垂落出一枚 Unified Track Notification 胶囊： 清晰展现歌曲名、艺人与高清封面，停留片刻后优雅吸附收缩回刘海， 体验如同 iPhone 灵动岛通知般从容自如。

  • 统一曲目通知胶囊，在合适的位置短暂浮现，不打扰当前窗口
  • 毫秒级 MediaRemote 原生捕获，支持 Spotify、Apple Music 等
  • 模拟物理弹簧曲线（Interactive Spring），收放自如
05 NATIVE VOLUME SLIDER HUD

音量流转，
触控级无级调节。

按下音量增减键时，屏幕中央不再有遮挡视线的庞大方块。 一枚 200×30 磨砂触感胶囊于刘海正下方轻盈浮现： 纯白滑块自左向右遮罩充盈，覆盖文字反色对比分明，支持无级平滑拖拽与键盘连击加速。

  • iOS 同款反色遮罩滑块，白底反转墨色字符，锐利优雅
  • 动态扬声器图标，静音瞬间无缝绘制对角线裁切动效
  • 支持键盘连击智能压缩条形高度（8pt 紧凑条），松手弹性复原
06 MAGSAFE CHARGING STATUS HUD

充能之间，
精准预估快充时光。

吸附 MagSafe 磁吸线时，刘海下方垂落 246×30 电池胶囊。 基于 macOS 内部权威能耗算法，以 Uneven 比例渐变绿色精准呈现电量与充满倒计时， 伴随无晕影的 Apple 绿呼吸脉冲闪电。

  • UnevenRounded 比例背景填充，右侧 1px 清晰高光截断线
  • 权威电池电量与“xx分钟充满”精准估算
  • 低电量提示、低电量模式与充满状态专属主题色彩映射
07 UNIX SOCKET LIVE ACTIVITIES API

极客之桥，
向所有终端与应用开放。

内置的 ExternalLiveActivityServer： 通过本地 Unix Domain Socket 暴露标准实时活动协议。 任何 Shell 脚本、Xcode 编译任务、下载进度或第三方工具，均可直接向 MacBook 刘海投送实时活动卡片。

  • 通过 Unix Domain Socket 本地高速通信，极低开销
  • 一行脚本即可向刘海推送构建完成、倒计时或自定义提醒
  • 探索属于 Mac 平台的开放式 Live Activity 体验
08 WINDOWS-STYLE SNAP LAYOUTS

移窗就范，
媲美 Windows 11 的灵动分屏。

拖拽任意 macOS 窗口靠近刘海或屏幕顶边，瞬时唤出精致的磨砂分屏选择器。 内置 5 种黄金比例布局预设，支持按住 Shift 一键智能排布桌面所有窗口。 更搭配独创的磨砂玻璃替身动画（Ghost Animator），位移归位丝滑流畅、告别原生闪烁。

  • 顶边灵动呼出：靠近刘海瞬时浮现 5 款分屏预设（对半、黄金分割、三等分、左主右副、四宫格）
  • Shift 智能排布：按住 Shift 键松手，一键将当前桌面所有窗口自动平铺归位
  • 毛玻璃替身动画：SkyLight 深度合成与弹簧物理曲线，无缝 Cross-fade 告别系统重绘闪烁
DESIGN PHILOSOPHY

少即是多，专注纯粹之美。

站在开源社区的肩膀上，专注于把 Live Activity 在 MacBook 刘海上的每一次呈现雕琢至极。

核心聚焦于 Live Activity

探索更纯粹的原生呈现。将全部状态汇聚至统一的 Live Activity 与 Alert 调度中心， 紧密围绕音乐律动、系统提示与事件通知，保持界面的轻盈与克制。

< 0.3% CPU 轻量表现

采用轻量单进程架构，进程内高效原生驱动，休眠期零负载，让 Mac 保持全天候冰凉续航。

专为内置刘海度身打造

精准贴合 MacBook 内置物理刘海的实际硬件曲率与边距，呈现自然无缝的视觉连贯性。

Windows 风格窗口吸附 · Snap Layouts

拖拽任意窗口靠近刘海或屏幕顶边，瞬时唤出 5 款预设分屏网格。按住 Shift 键更可一键将桌面所有窗口智能排布。独创毛玻璃替身飞行动画（Frosted Glass Ghost Animator），位移丝滑不闪烁。

开源透明，纯净守护

完全基于开源社区代码探索与自主迭代，不包含任何商业追踪或数据上传， 源码完全公开在 GitHub 上，自由查验与分享。
